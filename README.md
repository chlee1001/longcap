# LongCap

긴 웹 페이지를 한 장으로 캡처하고, 주석을 달고, 내보내는 Chrome 확장입니다. 캡처 원본과 편집 내용은 이 기기에만 저장되고 계정이 필요 없습니다.

## 기능

- 페이지 전체 캡처, 선택한 영역 캡처, 여러 페이지 일괄 캡처
- 보관함에서 검색, 선택 삭제, 선택 내보내기
- 주석 편집기: 사각형, 타원, 화살표, 직선, 텍스트, 강조, 가리기, 번호, 펜, 마커, 자르기
- PNG, JPEG, PDF 내보내기와 인쇄, 이미지 클립보드 복사
- PDF 가져오기

## 단축키

| 위치           | 키            | 동작                                                |
| -------------- | ------------- | --------------------------------------------------- |
| 브라우저 전체  | `Alt+Shift+S` | 페이지 캡처                                         |
| 브라우저 전체  | `Alt+Shift+E` | 영역 선택 캡처                                      |
| 브라우저 전체  | `Alt+Shift+L` | 보관함 열기                                         |
| 결과·편집 화면 | `Ctrl/Cmd+C`  | 이미지 복사 (객체나 텍스트를 선택한 경우 기존 복사) |
| 보관함·편집기  | `?`           | 단축키 목록                                         |

## 설치

```sh
npm ci
npm run build
```

`chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**로 `dist/` 폴더를 선택합니다.

## 개발

```sh
npm run typecheck
npm test
```

테스트용 고정 페이지는 `node scripts/fixtures.mjs`로 띄웁니다.
